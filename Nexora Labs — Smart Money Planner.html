Backup and restore

Your data lives only in this browser. Save a backup to recover it or move it to another device. The backup is not encrypted, so keep it private.

  1. Press Download backup for a full copy you can restore later, or an Export button for a spreadsheet of your expenses.
  2. If no file downloads (some in-app browsers and previews block it), copy the text that appears in the box below and paste it into a note or file.
  3. Keep the file somewhere private. It is plain text and not encrypted.
  4. To move to another device, or recover after clearing site data, open the app there and use Restore. Spreadsheet exports can’t be restored.
How to run and publish this project
  1. Run it: save this page as index.html and double-click it. It works offline in any modern browser; no install, server, or account needed.
  2. Where data lives: in your browser’s localStorage on this device only. Clearing site data or using “Reset demo data” restores the sample data. This app sends your entries nowhere, but the page does load its font from Google Fonts. Data does not sync between devices or browsers, and it is lost if you clear site data or use private browsing.
  3. Publish free: upload index.html to Netlify Drop (app.netlify.com/drop), Cloudflare Pages, Vercel, or a GitHub repo with GitHub Pages enabled. You get a public link in minutes.
  4. Privacy: the app never asks for bank details and never connects to a bank. Data is stored unencrypted in the browser, so anyone using this device and browser profile can see it. This app has not been security-tested, so don’t use it for sensitive financial records.
